# Active Directory Organizational Unit (OU) Structure

## Objective

To design and organize a structured Active Directory environment using Organizational Units (OUs) for centralized administration, user management and future Group Policy application within a Windows Server 2022 domain environment.

---

# Overview

Custom Organizational Units (OUs) were created to organize users, groups and computer objects within the Active Directory environment.

To design and organize a structured Active Directory environment using Organizational Units (OUs) for centralized administration, user management and basic Group Policy management within a Windows Server 2022 domain environment.

---


# Domain Structure

```text
Braganca.local
│
├── Braganca-Users
│   ├── IT
│   ├── HR
│   ├── Finance
│   └── Sales
│
├── Braganca-Groups
└── Braganca-Computers

```
