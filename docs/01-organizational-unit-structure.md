# Active Directory Organizational Unit (OU) Structure

## Objective

To design and organize a structured Active Directory environment using Organizational Units (OUs) for centralized administration, user management and future Group Policy application within a Windows Server 2022 domain environment.

---

# Overview

Custom Organizational Units (OUs) were created to structure the Active Directory environment based on departments and resource management.

This approach helps simulate a real-world enterprise environment by improving organization, simplifying administration and supporting future policy management.

---


# Domain Structure

```text
Braganca.local
│
├── Braganca-Users
│   ├── IT
│   ├── HR
│   ├── Finance
│   └── Sales
│
├── Braganca-Groups
└── Braganca-Computers

```
