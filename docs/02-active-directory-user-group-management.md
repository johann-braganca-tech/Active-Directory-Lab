# Active Directory User & Security Group Management

## Objective

To simulate common Active Directory administration tasks including user account creation, department organization and security group management within a Windows Server 2022 domain environment.

---

# Overview

User accounts and security groups were created and organized based on departmental structure to simulate a small business Active Directory environment.

This setup helps demonstrate common IT support and identity management tasks performed in enterprise environments.
